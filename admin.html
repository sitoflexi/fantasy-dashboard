Configuración inicial

Solo se hace una vez (y cuando caduque el token). El token se guarda cifrado con la contraseña; sin ella no sirve de nada.

  1. Abre GitHub → Fine-grained token nuevo con la cuenta dueña del repo.
  2. Nombre: fantasy-admin. Caducidad: la máxima que permita (1 año).
  3. Repository access → Only select repositories → fantasy-dashboard.
  4. Permissions → Repository → Contents: Read and write. Nada más.
  5. Genera el token, pégalo aquí y elige una contraseña larga (mín. 12 caracteres).

Jornada

Mete los puntos de cada plantilla (los de la clasificación de la jornada en la app) y, si hay, las rojas y los no alineados. El pago se calcula solo. «Otros» es para importes de rojas / no alineados sin desglosar; «Ajuste» suma o resta a mano.

Jugadores

Nombre que se muestra y nombre de su plantilla en la app.

Sesión

Cambiar la contraseña cifra el mismo token con la nueva contraseña.
